# Shiplet Lab

Shiplet Lab builds open tools and managed infrastructure that help small teams turn software prototypes into dependable applications.

## Projects

- [Capsule Kit](https://github.com/Shiplet-Lab/capsule-kit) — an open runtime contract and readiness checker for small applications.

## Get involved

We are building in public. Watch the repositories, open an issue, or contribute an adapter for your preferred runtime or cloud provider.
